# Animation craft

Adapted from Emil Kowalski's [animate skill](https://github.com/emilkowalski/skills/blob/main/skills/animate/SKILL.md) (MIT; [license](https://github.com/emilkowalski/skills/blob/main/LICENSE)).

First decide whether motion helps feedback, state, spatial continuity, explanation, or occasional delight. Keep frequent actions immediate. Choose CSS transitions for simple state changes and CSS animation for predetermined ambient effects; consider a library for gestures, spring physics, exit, or layout choreography that needs it. Prefer transform and opacity, name transitioned properties, and make user-triggered changes interruptible. An entrance usually decelerates; keep controls quick and exits spatially consistent. Gate hover effects for suitable pointers and provide a gentler or static reduced-motion state. Check motion in a browser and under interruption.

For The Whale, water ripples are the sole ambient style. Keep them behind content and keep the specimen grid and mixer usable without them.
