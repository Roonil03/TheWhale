# Watermelon UI

Adapted from [Watermelon's skill](https://github.com/WatermelonCorp/watermelon-platform/blob/main/skills/watermelon-ui/SKILL.md) (MIT; [license](https://github.com/WatermelonCorp/watermelon-platform/blob/main/LICENSE)). Its catalog is React and Tailwind; the original describes a public read-only MCP endpoint at `https://mcp.watermelon.sh/mcp`.

If that MCP is available and an example would help, search by functional and visual need, compare suitable previews, and retrieve the chosen source and dependencies before deciding whether to use it. For full pages, inspect proposed sections individually. Adapt tokens, copy, imports and interaction to the existing product; verify responsive layout, keyboard access and supported themes. If the endpoint is unavailable, inspect the public catalog or use a local solution. Do not imply the MCP was queried if it wasn't.

The Whale uses React and plain CSS. Borrow the selection and composition approach; do not initialize Tailwind or install components just to satisfy a reference.
